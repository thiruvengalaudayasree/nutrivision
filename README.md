# 🥗 NutriVision – AI-Powered Nutrition Health Score Analyzer

NutriVision is an AI-powered web application that analyzes food images and generates a nutrition health score report. Simply upload a food image, and the system identifies the meal using AI, estimates its nutritional value, and provides an easy-to-understand health score to help users make healthier food choices.
